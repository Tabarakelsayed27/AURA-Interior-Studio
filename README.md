# AURA | Interior Design Studio

AURA is a modern and elegant interior design studio website designed to showcase creative interior spaces and professional design services.

## About The Project

AURA provides a clean and attractive online experience for visitors to explore interior design services, meet the design team, and contact the studio.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS

## Features

- Modern and elegant user interface.
- Fully responsive design using Tailwind CSS.
- Interactive navigation menu.
- Smooth scrolling and animations.
- Services section.
- Team members section.
- Contact section.
- Hover effects and interactive elements.

## How To Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enjoy exploring AURA Interior Studio!
